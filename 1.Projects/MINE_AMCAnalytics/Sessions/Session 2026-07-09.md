# Session — 9 juillet 2026

Projet : [[AMC Analytics]]

## Contexte

Reprise du volet **data** d'AMC Analytics : brancher le sous-module **Full Funnel** directement sur BigQuery (au lieu de l'upload CSV manuel). Khadija n'ayant pas encore posé la donnée en BQ, on a chargé nous-mêmes les CSV pour avoir une première version fonctionnelle.

## Ce qui a été fait

### 1. Fondation data BigQuery

- Projet `amira-test`, région **EU** (⚠️ `EU` multi-région ≠ `europe-west1`).
- **Un dataset par client** : `AMC_ConnectedHub_7cR1jE` (L'Oréal), dérivé du customerId ConnectedHub → isolation par client au niveau dataset.
- **Nomenclature** : tables analyse `<étude>__<marque>__<période>` (ex. `full_funnel__mugler__2025_q4`) ; dashboards natifs futurs en `dash_*`.
- **Registre** : table `registry` (une ligne par table analyse : libellés UI, dates réelles, `row_count`, `is_active`).
- **Ingestion** : script de transformation des CSV AMC (`;`, décimales virgule→point, dates `JJ/MM/AAAA`→ISO, colonne `path` intacte) → tables non partitionnées, schéma `tb_media_mix_path_to_conversion`.
- Données chargées : **Mugler** (298 l.) + **Azzaro** (1366 l.).
- **Abandon du split dev/prod** en cours de route : on est repassé d'un dataset `_dev` + prod à un **seul dataset par client** (simplicité ; contrepartie : plus d'isolation staging).

### 2. Intégration repo ConnectedHub (branche `feat/amc-full-funnel-bigquery`)

- **Backend** (le client ne touche jamais BQ) : instance BQ `amira-test`, dérivation `dataset = AMC_ConnectedHub_<customerId>`, routes `GET /analyses` (catalogue via registre + `last_modified_time` depuis `__TABLES__`) et `GET /analyses/:tableId` (lecture, `tableId` validé contre le registre, valeurs sérialisées en string).
- **Frontend** : hooks `useListAmcAnalyses` / `useGetAmcAnalysisData` ; extraction du cœur config/generate (`ConfigureAndGenerate`) hors de `data-upload-tab` ; nouveau `AnalysisSelectStep` (sélection depuis BQ) ; `full-funnel.tsx` recâblé `select → configure → deck`. L'upload CSV est retiré.
- **Tests** : 13 tests serveur (helpers + routes), verts.

### 3. UI de sélection (itérations)

- Picker sans choix de « study » (fixé par le sous-module) ; boutons horizontaux `MARQUE Période`.
- Carte récap (Période / Rows / Last Updated) qui s'ouvre **sous la vignette sélectionnée** (flex `basis-full`).
- Couleur de sélection neutre gris foncé (inversée en dark mode), animation « drop » via framer-motion, toggle (reclic = désélection).
- « Extracted » → **« Last Updated »** (dernière modif réelle de la table via `__TABLES__.last_modified_time`) pour une notion d'historique.
