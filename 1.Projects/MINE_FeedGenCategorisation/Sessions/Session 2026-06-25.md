Projet : [[FeedGen Catégorisation]]

## Ce qui a été fait

- Endpoint Vertex AI Vector Search déployé et opérationnel (`feedgen_taxonomy_2` sur `indexEndpoints/84464483245752320`)
- Testé `search_taxonomy_vertex()` sur la description complète d'une table guéridon — résultats incorrects (top 5 = tables de sport)
- Testé sur description courte "Table guéridon ronde en aluminium, plateau 70cm" — toujours incorrect (billard, ping-pong, air hockey)
- Échangé avec Dan sur le choix description vs titre comme input

## Conclusions

**Limitation de l'approche embedding identifiée** : le mot "table" matche les tables de sport (billard, ping-pong) plutôt que l'ameublement. L'embedding fait du matching lexical, pas de raisonnement sémantique sur le contexte produit.

**Retour de Dan** :
- Son approche LLM a besoin de la description enrichie (feedgen) pour bien fonctionner — sans elle, performance dégradée
- Notre approche RAG/embedding a besoin de texte court → les titres sont plus adaptés
- Les deux approches sont complémentaires : elles couvrent des cas différents selon le flux client
