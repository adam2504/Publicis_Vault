# Point Alternante Epsilon — Data & IA

Échange informel initié par curiosité — voir ce qui se fait chez les autres alternants data/IA dans le groupe Publicis (Epsilon, profils plus techniques).

## Contexte

- Tafsouth — Apprentie Ingénieur Data & IA chez Epsilon France (groupe Publicis)
- Master 2 Ingénierie en IA, Université Paris 8 (sept 2024 – août 2026)
- Initiative perso pour benchmarker les missions et pratiques inter-agences

## Son profil (LinkedIn)

**Projets chez Epsilon (depuis sept 2025) :**

- **Score on the Fly** (déployé sur Next by Epsilon) : moteur de scoring prédictif pour audiences CRM, pipeline ML complet (feature engineering temporel, fenêtres glissantes, calibration, anti-leakage), agent conversationnel LangChain/LangGraph/Gemini avec RAG et tool calling, FastAPI + MLOps GCP (Vertex AI, BigQuery) — AUC 0,89–0,96

**Avant Epsilon :** Data Analyst chez SNCF Réseau (1 an) — SQL Server, pipelines Python, dashboards Power BI

**Stack principale :** LangGraph, Docker, Terraform, FastAPI, GCP (Vertex AI, BigQuery, Cloud Run), LangChain, Gemini

**Profil :** très orienté MLOps + IA générative, projets déployés en prod — plus technique que data analytics

## Notes de l'échange

**Organisation Epsilon :**
- Plusieurs pôles : Data & IA (1 000 personnes), RH, Marketing, Communication
- Pôle Data & IA divisé en 2 sous-pôles : Produit (data science / data analyst) et Gouvernance/Métiers
- Modèle : 80 % consultants chez le client, 20 % "en attente" au bureau travaillant sur des projets R&D internes
- Les "en attente" peuvent être appelés chez un client à tout moment — le pôle Communication soigne les CVs pour les présenter aux clients, qui choisissent ensuite

**Management :**
- Manager peu présent (rôle surtout administratif)

**Alternants :**
- Epsilon a monté une pépinière pour former les alternants et les embaucher en CDI
- Tafsouth n'a pas été prise faute de clients disponibles actuellement
- 5 anciens alternants (dont 1 encore présent), + 2 arrivés en sept 2025 (Tafsouth + une autre)
- Bonne ambiance entre alternants (déjeuners ensemble)

**Plateforme Next by Epsilon :**
- Plateforme interne regroupant les projets R&D Epsilon
- 80 % des projets développés par alternants et stagiaires
- Score on the Fly : on importe une base de données client, le modèle ML score les profils par appétence produit et recommande des audiences CRM à cibler

## Stack / outils mentionnés

- LangChain, LangGraph, Gemini (agent conversationnel + génération de contenu)
- FastAPI, Docker, Cloud Run, Gunicorn, Nginx (déploiement)
- GCP : Vertex AI, BigQuery (MLOps, expérimentations)
- Terraform (infra as code)
- Power BI, SQL Server (expérience SNCF)

## Ce que j'ai appris / points intéressants

- Epsilon fonctionne comme une ESN interne à Publicis : modèle consultant, CVs gérés par le pôle comm, clients qui choisissent les profils
- Alternants très autonomes et producteurs de vraie valeur (Next by Epsilon = 80 % alternants/stagiaires)
- Profil bien plus MLOps/ingé que data analyst — pipeline ML en prod, agents IA déployés, infra GCP complète
- Pépinière = intention d'embauche CDI, mais conditionnée aux besoins clients (pas garanti)
- Modèle très différent de Publicis Media : pas de client fixe, missions variables, moins de contexte métier long terme
